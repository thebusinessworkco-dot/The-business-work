How to Use in React / Next.js Components

The <Logo /> component in src/components/Logo.tsx supports all variants with responsive sizes and custom colors:

// 1. Full logo (Header, Footer)
import Logo from "@/components/Logo";
<Logo />
<Logo small />

// 2. Left mark / emblem only (Square icon)
<Logo variant="mark" className="w-8 h-8" />
// Or using helper:
import { LogoMark } from "@/components/Logo";
<LogoMark className="w-10 h-10 text-ink" />

// 3. Right text / wordmark only
<Logo variant="text" className="w-48 h-auto" />
// Or using helper:
import { LogoText } from "@/components/Logo";
<LogoText className="w-52 h-auto text-ink" />
